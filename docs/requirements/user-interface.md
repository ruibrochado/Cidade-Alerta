# User Interfaces

This document presents the main user interface designs and interaction flows developed for the Cidade Alerta platform.

The application's interface was designed with a strong focus on simplicity, accessibility, and fast interaction, ensuring that users can report, browse, and monitor urban issues with minimal friction.

The following sections showcase the most relevant screens, interaction flows, and user-centered functionalities implemented throughout the project.

---

## Design Principles

The interface design followed the following principles throughout development:

- Simplicity and ease of use;
- Mobile-first design;
- Clear visual hierarchy;
- Accessibility and readability;
- Minimal interaction friction;
- Fast navigation between core functionalities;
- Consistent feedback and status communication;
- User-centered interaction flows.

## Final Remarks

The interfaces evolved iteratively throughout the project based on team discussions, usability considerations, and empirical validation conducted with potential users.

Special attention was given to reducing interaction friction, improving accessibility, and creating a seamless mobile-first experience that encourages citizen participation in urban issue reporting and environmental awareness.
