# User Interfaces

This document presents the main user interface designs and interaction flows developed for the Cidade Alerta platform.

The application's interface was designed with a strong focus on simplicity, accessibility, and fast interaction, ensuring that users can report urban issues with minimal friction.

The following sections showcase the most relevant screens and visual flows implemented throughout the project.

---

## Design Principles

The interface design followed the following principles throughout development:

- Simplicity and ease of use;
- Mobile-first design;
- Clear visual hierarchy;
- Accessibility and readability;
- Minimal interaction friction;
- Fast navigation between core functionalities.
