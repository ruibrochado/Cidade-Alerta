# User Interfaces

This document presents the main user interface designs and interaction flows developed for the Cidade Alerta platform.

The application's interface was designed with a strong focus on simplicity, accessibility, and fast interaction, ensuring that users can report, browse, and monitor urban issues with minimal friction.

The following sections showcase the most relevant screens, interaction flows, and user-centered functionalities implemented throughout the project.

---

## Design Principles

The interface design followed the following principles throughout development:

- Simplicity and ease of use;
- Mobile-first design;
- Clear visual hierarchy;
- Accessibility and readability;
- Minimal interaction friction;
- Fast navigation between core functionalities;
- Consistent feedback and status communication;
- User-centered interaction flows.

---

## Authentication Screens

The authentication interfaces were designed to provide a familiar and intuitive login and registration experience.

The authentication flow includes:

- Citizen Sign In;
- Citizen Sign Up;
- Secure session management;
- Logout functionality;
- Form validation and authentication feedback dialogs.

The design prioritizes accessibility, simplicity, and quick account access.

## Home Screen / Main Page

The home screen acts as the main page of the application, providing users with access to the public issue feed and the platform's core functionalities.

The interface includes:

- Main public issue feed;
- Quick access to report submission;
- Activity feed with recent community reports;
- Voting on reported issues;
- Commenting on reports;
- Prioritization of reports based on vote score;
- Sorting reports by different criteria;
- Filtering reports by city;
- Filtering reports by issue type;
- Notifications and report updates.

The design prioritizes clarity, readability, community participation, and fast navigation between features.

## Incident Reporting Flow

The incident reporting interface was designed to minimize the number of steps required to submit an issue.

The reporting flow includes:

- Issue categorization;
- Title and description input;
- Photo upload;
- Automatic location detection;
- Interactive map location confirmation;
- Report review before submission;
- Success and error feedback dialogs.

The overall flow was designed to be intuitive, fast, and mobile-friendly.
